I'm approaching front-end development as a beginner, with a stronger background in visual and interface design than in writing production code.

That distinction matters. I can work through the visual decisions of an interface, but translating those decisions into responsive, accessible behavior is a separate skill I want to improve.

## What I'm focusing on first

My starting priorities are the fundamentals:

- **HTML:** document structure, semantic elements, links, forms, and accessible content.
- **CSS:** layouts, responsive behavior, spacing systems, and typography.
- **JavaScript:** understanding interactions and how a page responds to user actions.
- **Practice:** building small things, noticing what breaks, and learning to debug them.

This isn't a claim that I've completed all of these topics. It's a direction for what I want to learn.

## How design and code connect

Working in design tools teaches you to consider hierarchy, components, alignment, and states. Learning front-end development adds new questions: Does the layout work without a mouse? What happens on a narrow screen? What if text wraps differently? What if a user prefers reduced motion?

I want to get better at thinking about those details while designing, not only after handing a file to a developer.

## What this journal is for

I'll use the learning log to record practical updates once I have something real to share—a small experiment, a layout I've implemented, or a problem I've solved.

For now, this is my starting point. Progress will be documented as it happens.
